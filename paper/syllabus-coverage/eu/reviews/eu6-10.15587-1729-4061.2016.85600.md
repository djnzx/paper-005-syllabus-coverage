**Journal:** Eastern-European Journal of Enterprise Technologies, Vol. 6, No.

## 1. Problem

The authors target the recognition of complex anomalies and targeted
cyber-attacks in computer systems (CoS) by an adaptive, self-learning expert
system (AES). The motivating phenomenon is that attackers increasingly use
previously unknown malware and vulnerabilities, so static signature methods
cannot keep pace.

They identify a precise gap. Prior recognition systems built on finite
automata [1], machine learning [2, 3], neural networks [4, 5], Bayesian
networks [6], genetic algorithms [7], fuzzy logic [8], and statistical
analysis [9] "address only the basic features of cyber-attacks," partly because
computing the information distance between individual features is hard.
Clustering approaches using the Bayesian information criterion [12] or
Kullback-Leibler divergence [13, 14] examined "cyber attacks of a certain class
only," narrowing applicability.

The central, explicitly stated gap is that most prior work ignores **errors of
the third kind** — those arising when SIRCT models omit certain recognition
procedures — and that the attribute-space partition differs across CoS. Hence
the need for an information indicator of functional performance (IIFP)
accounting for statistical and deterministic optimization parameters when
clustering illegal-activity attributes.

## 2. Research Tasks and Objectives

Section 3 sets the aim: a model for determining the IIFP of training an expert
system, incorporating statistical and distance clustering parameters for
threats, anomalies, and attacks, plus third-kind errors during machine learning.
Three tasks follow: (1) develop a structural scheme of the AES; (2) design a
functional-effectiveness model based on the entropic and information-distance
Kullback-Leibler criterion for clustering attributes; and (3) test the AES and
determine the rational number of clusters in the attribute space.

The work explicitly targets recognition modeling, not the deployment of
countermeasures themselves.

## 3. Methods

The optimization objective
is $SI=\arg\max_{CO^{ad},CM^{ad},ME^{ad}} SI(CO^{ad},CM^{ad},ME^{ad}\mid\Lambda)$ (
eq. 1), constrained by vulnerable sections, attack windows, and protection cost.
Training data form a multidimensional binary training matrix (MBTM), with
object-of-recognition (OR) properties — vulnerability type, protocol, channel,
object type — encoded in binary or non-negative integers (Table 1). The module
MFBVR binarizes vectors using multifractal analysis, the Hurst indicator, and a
moving window.

Functional effectiveness uses entropy $H_{SS'}=-\sum P_{SS_i}\log_2 P_{SS_i}$ (
eq. 8) and information distances $DIS(M\Theta_i,M\Theta_L^*)$ between clusters
with a voting procedure (eqs. 9–11). The normalized entropic IIFP $CE$ (eq. 12)
and the full training criterion (eq. 13) explicitly carry first-, second-, and
third-kind error terms $mis1,mis2,mis3$ over hyperspheric containers of
radius $cr$. Three hypotheses (normal / below-norm / above-norm IE) feed a
Bernoulli-Laplace estimate (eq. 18) and a Bayesian decisive rule (eq. 19)
assigning detected OR to known or unknown classes.

The software AES **"Threat Analyzer"** was built in Delphi with the **CLIPS**
expert-system shell, using a frame model with direct logical inference, and
validated on the **KDD-99** dataset (Table 4).

## 4. Key Results

Testing at enterprises in Kyiv, Dnipro, and Chernihiv showed detection of
standard attack classes at **76.5%–99.1%**, comparable to hybrid neural networks
and genetic algorithms. Per-class error rates were reported: DoS/DDoS — 10.2% (
first kind) / 2.86% (second); Probe — 12.1% / 3.15%; R2L — 9.4% / 2.75%; U2R —
11.3% / 3.5%.

A central finding is that the **optimal number of clusters is 3**, and
representative attribute sets of only **5–7 attributes** suffice. Crucially, "
MILT for AES" required only **10–12 input data** versus **41** for the
support-vector method (Table 4) while still adapting to third-kind errors and
detecting new attributes. For very small attribute counts (2–4), MILT beat
support vectors on $CE$ by **25–50%**, but trailed a hybrid neural network by *
*20–55%**.

## 5. Conclusion

The authors conclude they delivered a self-learning AES scheme that accounts for
accumulating third-kind errors, an entropic/Kullback-Leibler IIFP model yielding
correct decisive rules, and a validated "Threat Analyzer" achieving 76.5%–99.1%
recognition with an optimal cluster count of 3. The system was implemented at
the railway-transport automation bureau of Ukraine's Ministry of Infrastructure.
Future work targets enriching the attribute knowledge base and testing on larger
object sets.

One caution: the headline accuracy is uneven — U2R reaches only 76.5%, below
several baselines — and the authors concede the effect is "insignificant" when
few attributes are available; reliance on the aging KDD-99 benchmark also limits
how far the results generalize to modern traffic.
